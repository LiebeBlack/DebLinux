Ligero por diseño, verificable por defecto.

Nada de escritorios de 2 GB ni de desactivar el firmware «un momento». Cada pieza está elegida para el Celeron N4120 y cada eslabón de arranque se comprueba automáticamente antes de publicar la ISO.

Pipeline

De live-build a una ISO que arranca.

Seis etapas en GitHub Actions sobre Ubuntu, cada una con su comprobación. Si algo no cuadra, el job falla antes de publicar artefactos.

01

Compilación con live-build

Debian 13 (trixie) con squashfs zstd, snapshot inmutable en el bootstrap y mirror vivo en el resto para que el sistema instalado siga recibiendo actualizaciones de seguridad.

02

Kernel Debian intacto

El vmlinuz de linux-image-amd64 ya lleva la firma PE/COFF de Debian. No se ejecuta sbsign: se copia tal cual a /live/vmlinuz y sbverify confirma que la firma Debian sigue ahí.

03

ESP a partir de efi.img

boot/grub/efi.img se añade como partición EFI del GPT. Contiene shim, GRUB y su configuración; no se inyecta mmx64.efi porque no hay MOK que gestionar.

04

GPT + MBR protector

La ISO se reconstruye con un GPT válido y un MBR protector 0xEE, sin APM, sin código BIOS y sin entrada El Torito BIOS. El arranque por USB usa el ESP; el arranque por CD usa El Torito UEFI.

05

Reconstrucción UEFI-only

La ISO final se genera con -append_partition 2 0xef, -appended_part_as_gpt y -partition_offset 16, conservando volumen y metadatos del original. Nada de -isohybrid-gpt-basdat: sin -isohybrid-mbr xorriso la ignora y el GPT no se escribe.

06

Verificación y arranque real

Se comprueba el GPT en el LBA 1, el MBR protector 0xEE, la ausencia de APM y de código BIOS, la entrada El Torito UEFI, las firmas Microsoft/Debian y la firma Debian de cada kernel. Después la ISO se arranca en QEMU con OVMF Secure Boot como disco USB hasta ver login: en el puerto serie.

# reconstrucción UEFI-only (sin sudo: solo lee la ISO)
./scripts/repack-iso.sh live-image-amd64.hybrid.iso \
    debian-live-lenovo300e-uefi.iso

# layout + cadena Secure Boot de Debian
./scripts/verify-iso.sh debian-live-lenovo300e-uefi.iso

# arranque real con OVMF Secure Boot (USB por defecto)
./scripts/boot-test-iso.sh debian-live-lenovo300e-uefi.iso

Primer arranque

Cuatro pasos y Secure Boot sigue encendido.

La ISO usa la cadena firmada de Debian: no hay MOK que enrolar. No hay que desactivar nada en el firmware ni entrar en setup.

Graba la ISO en un USB

Sirve dd, Ventoy o cualquier grabador que escriba la imagen tal cual: la ISO es UEFI-only, con GPT, MBR protector y entrada El Torito UEFI.

sudo dd if=debian-live-lenovo300e-uefi.iso \
    of=/dev/sdX bs=4M status=progress oflag=sync

Arranca desde el USB con F12

Enciende la Lenovo 300e y abre el menú de arranque del firmware. Elige el USB: la ISO arranca directamente con Secure Boot activado, sin enrolar ninguna clave.

Instala con Calamares

Calamares exige GPT con partición EFI. Deja que cree la tabla y el ESP; el instalador coloca shim y GRUB firmados por Debian, y el kernel instalado ya viene firmado. No hay MOK ni pasos extra: el instalador deja además shim en EFI/BOOT antes de reiniciar, así que el primer arranque no depende de la NVRAM ni de entrar en setup.

Arranca el sistema instalado

El sistema instalado usa la misma cadena Debian. El instalador ya deja shim en EFI/BOOT antes de reiniciar y efi-removable-fallback lo verifica y repara en cada arranque, para que la laptop siga arrancando si el firmware pierde la entrada NVRAM; no copia mmx64.efi.

Preguntas frecuentes

Lo que suele frenar a la gente.

¿Por qué no hay que enrolar ninguna clave?

Porque Debian ya firma sus kernels de linux-image y su shim incluye la CA de Debian. La cadena shim → GRUB → kernel se valida con las firmas que ya trae la ISO; no se genera ninguna MOK.

¿Tengo que desactivar Secure Boot para instalar?

No. La ISO arranca con Secure Boot activado y no necesita enrolar nada; el instalador deja el respaldo shim listo antes de reiniciar, así que tampoco hay que entrar en setup. Si el firmware no lista el USB, usa «Boot from file» y selecciona EFI/BOOT/BOOTX64.EFI de la partición EFI del medio.

¿Arranca en otro portátil?

Debería arrancar en cualquier equipo UEFI x86_64, pero la ISO está afinada para la 300e: firmware Intel, audio SOF, GPU UHD 600 y gestión de energía de portátil. En otro hardware funcionará como un Debian live normal, sin esas optimizaciones.

¿Cómo sé que la ISO que descargué arranca?

Cada compilación arranca la ISO UEFI como disco USB en QEMU con OVMF Secure Boot y espera a ver el prompt login: en el puerto serie. Eso demuestra que el firmware aceptó shim, shim aceptó GRUB, GRUB cargó el kernel firmado por Debian y systemd llegó a userspace. El log y las capturas quedan como artefacto del run.
